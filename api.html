Bollywood Product API Directory

A categorized, searchable reference list of all backend API endpoints integrated inside the application codebase.

Total Categories: 6
Total APIs: 18

Movies & Films

Film Details GET
https://hindi.bollywoodproduct.com/api-film-details.php?unique_id={id}
Fetches complete metadata, release detail, genre, director, producers and cast for a single film.
Latest Movies GET
https://bollywoodproduct.com/api-latest-movies.php
Returns a list of recently released movies in the database.
Upcoming Movies GET
https://www.bollywoodproduct.com/api-upcoming-movies.php
Returns upcoming theater releases list.
Full Movies GET
https://www.bollywoodproduct.com/api-full-movies.php
Lists all movies fully available to watch on platforms or YouTube.
All Movies (Glance) GET
https://www.bollywoodproduct.com/api-all-movies.php
Fetches a combined directory list of various items.
Master Films List (Cache) GET
https://www.bollywoodproduct.com/api-films.php
Large JSON list of ~9000+ movies used locally in the app for local searching and offline caching.
Dubbed Movies GET
https://www.bollywoodproduct.com/api-dubbed-movies.php
Retrieves movies dubbed in alternative regional languages.

Trailers & Videos

Trailers Directory GET
https://hindi.bollywoodproduct.com/api-trailers.php
Fetches list of movie trailer updates.
Latest Trailers GET
https://www.bollywoodproduct.com/api-latest-trailers.php
Returns the most recently uploaded trailers.
Most Viewed Trailers GET
https://www.bollywoodproduct.com/api-most-viewed-trailers.php
Gets the trending/most viewed trailer videos.

OTT Releases

OTT Movies Directory GET
https://www.bollywoodproduct.com/api-ott-movies.php
Lists available digital/streaming releases on platforms like Netflix, Prime, Hotstar etc.
Latest OTT Releases GET
https://www.bollywoodproduct.com/api-ott-latest-movies.php
Recent OTT digital releases updates.
Upcoming OTT Releases GET
https://www.bollywoodproduct.com/api-ott-upcoming-movies.php
Announced upcoming digital releases list.

Latest Songs

Latest Songs List GET
https://www.bollywoodproduct.com/api/songs/latest.php
Fetches the list of newly added Bollywood film audio songs and videos.

Cast & Celebrities

Today's Birthdays GET
https://bollywoodproduct.com/api-today-cast-birthday.php
Lists cast members and stars celebrating their birthdays today.
Tomorrow's Birthdays GET
https://www.bollywoodproduct.com/api-tommorow-cast-birthday.php
Lists cast members and stars celebrating their birthdays tomorrow.

Utility & External APIs

YouTube Metadata (NoEmbed) GET
https://noembed.com/embed?url=https://www.youtube.com/watch?v={videoId}
Used to parse video information (such as titles, dimensions) without requiring direct Google/YouTube key credentials.
YouTube Image Thumbnail GET
https://img.youtube.com/vi/{videoId}/0.jpg
Static video thumbnail path used to load image posters dynamically inside the app UI.
